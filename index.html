📌 模拟数据声明 (Notice)：
本看板展示的所有核心指标（包括用户规模、Token 消耗量、转化留存模型、分时趋势及场景分布等），均为面向 Wenty-test 平台进行内部测试、功能演练与可视化大屏适配生成的模拟仿真数据集（Simulated Test Data），不包含任何外部生产隐私与机密数据。
时间范围与分时过滤

右上角时间段控制器可联动过滤趋势、画像、渠道、留存、漏斗与模型消耗等分时指标；「累计部署实例数」为平台有史以来的全局基线累计值，不受所选起始日期的约束。

  • 数据来源：simulation/datasets/opsDailyQuality_simulated.sql
  • 基线指标：simulation/datasets/lifetimeDeployTotal_simulated.sql
运营总览与核心指标

实例部署为所选时间段内完成有效 Wenty 实例部署的用户数；新用户为注册日期等于首次使用日期的用户；老用户为注册日期早于使用日期的活跃老用户；日均 Token 为时间段内消耗总 Token 除以有效天数。

  • 累计部署实例数：全周期累计有效实例部署总和，截至所选结束日期。
  • 新老用户结构：按每日用户身份标签汇总聚类。
  • 数据来源：simulation/datasets/opsDailyQuality_simulated.sql
运营趋势复合图

蓝色折线展示每日新增实例部署趋势；蓝紫堆积柱展示每日新老用户活跃结构；青色折线展示每日总 Token 吞吐量（右轴单位：亿 Token）。

  • 图表加载：仅在首次进入或应用新筛选日期时播放动效；Hover 交互仅展示即时 Tooltip 与高亮。
  • 数据来源：simulation/datasets/tokenDaily_simulated.sql
付费转化与健康漏斗

以付费用户基线为基准，依次展示「已部署实例」、「已首次使用」、「次日留存」、「深度对话用户」四个转化阶段。

  • 已部署实例：付费用户中完成有效 Wenty 实例部署的规模。
  • 已首次使用：部署后发生首次有效交互的人数。
  • 次日留存：第 2 个自然日依然产生交互活跃的用户。
  • 深度对话用户：在统计周期内累计会话 Session 数达到 4 个及以上的核心高价值用户。
  • 数据来源：simulation/datasets/opsActivationFunnel_simulated.sql
渠道来源与留存流向 (桑基图)

桑基图直观呈现从各入口渠道（直接流量、精准推广、SEO、生态协同等）到部署用户、当日活跃、3天留存及待激活流向。

  • 流失用户：当日使用后未进入后续 3 天活跃留存的用户群体。
  • 待激活：已完成实例部署但未在当日产生深入调用的用户。
  • 数据来源：simulation/datasets/channelFunnel_simulated.sql
用户画像与分层聚类

画像板块按新老结构、活跃天数跨度、使用频次、Token 消耗分层、会话深度与核心业务场景进行多维聚合。

  • 高消耗用户池：按用户 Token 消耗区间（如百万级、千万级等）梯度分层。
  • 场景排行：按不同 AI 场景分类（工程构建、分析决策、内容创作等）的消息总量排序。
  • 数据来源：simulation/datasets/opsUserQualitySegments_simulated.sql
模型 Token 消耗分布 (Treemap)

按大语言模型维度汇总 Token 消耗量，面积大小代表 Token 贡献比重（单位：亿 Token）；支持悬停交互查看模型全称与精准占比。

  • 主力模型：Token 消耗排名前列的核心基座大模型（如 Wenty-Core-v5, DeepSeek-V4, Spark-X2 等）。
  • 长尾模型：长尾轻量化推理与垂类微调模型。
  • 数据来源：simulation/datasets/modelUsage_simulated.sql
Wenty-test 智能问数

本功能支持针对当前大屏指标快照进行自然语言提问与即时分析。在纯前端静态部署环境下，系统将自动基于本地缓存快照与内置语义规则引擎进行秒级分析与回答。

  • 数据来源：当前页面已加载的模拟指标快照。
  • 本地模式：支持关于模型消耗、留存转化、用户画像及总体规模的即时语义匹配。
